# 94nesha Golf Fest 2026

Live site: https://94nesha.id

Tournament website for **94nesha Golf Fest 2026**: ITB Alumni Class of 1994, Saturday 28 November 2026, Damai Indah Golf BSD Course. Shotgun start 12.30 WIB.

The site is a single self-contained page (`index.html`) in Bahasa Indonesia and English. It covers the schedule, prize holes, prizes, live scores and winners (System 36 with countback), rules, the ITB 94 golf shirt, sponsors and the Beasiswa 94 scholarship.

## Updating

Event data (play status, pars, players, novelty and hole-in-one winners, sponsors, scholarship total) lives in the `DATA` block near the bottom of `index.html`. Edit it and commit; GitHub Pages republishes automatically.

Organised by Perkumpulan Golf ITB 94.
